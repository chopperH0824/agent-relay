# Agent Relay v0.1.0

The first executable Agent Relay release turns the repository's handoff design into an installable Agent Skill and a dependency-free project runtime.

## Install

```bash
npx skills add chopperH0824/agent-relay --skill agent-relay
```

GitHub CLI 2.90.0+ preview, pinned to this release:

```bash
gh skill install chopperH0824/agent-relay agent-relay@v0.1.0
```

Then ask the agent inside a target project:

```text
Use agent-relay to initialize this project. Show the dry-run and every file change first; after confirmation, apply it and run doctor.
```

## Highlights

- One-time initialization leaves `.agent-relay/`, `AGENTS.md`, and thin harness adapters in the project.
- Python 3.9+ standard-library runtime; no daemon, service, telemetry, package dependency, or runtime network call.
- Durable goals, task leases, conservative write-scope conflicts, event records, environment fingerprints, and generated handoff summaries.
- Read-only concise, full, and JSON reports with a bundled v1 JSON Schema.
- Non-overwriting `vNNN` version sealing with Git metadata, artifact copies, SHA-256 manifests, and doctor verification.
- Dry-run, bounded managed blocks, pre-change backups, atomic writes, safe uninstall, and explicitly confirmed purge.
- Minimal, auto, and all adapter modes for standard Agent Skills hosts and popular international and Chinese agent harnesses.
- Manual WorkBuddy bridge guidance without inventing an undocumented `skill.yml` schema.

## Verification

- 16 unit and integration tests.
- Python 3.9, 3.11, and 3.13 CI matrix.
- Local `npx skills` discovery and copied Pi installation verified.
- Desktop and mobile README/architecture visual checks.
- Secret redaction, malicious managed-path containment, symlink rejection, checksum tamper detection, report immutability, and uninstall preservation covered by tests.

## Important boundaries

- Project instructions guide agent behavior; they cannot override system, organization, or user policy.
- Semantic finalization is interpreted by the agent. The runtime only seals explicit artifact parameters.
- Generated adapters passing local tests does not imply every closed-source harness has passed a live-session regression.
- v0.1 locks target a same-machine local filesystem, not distributed or cloud-sync consistency.
- Review Skills before installation; they run with the permissions granted by the host agent.
