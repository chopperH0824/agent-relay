# Agent Relay v0.1.1

This maintenance release improves the reliability of handoff summaries and upgrades without migrating existing project history.

## Highlights

- Blocked and cancelled tasks are no longer reported as completed. Blocked work and completion caveats remain visible.
- The project summary follows the most recently updated explicit goal; inferred candidates remain labeled.
- Doctor warns about expired active leases and runtime ownership mismatches.
- Git and non-Git projects can compare selected files with the latest sealed artifact manifest. Reports label coverage and distinguish changed, missing, unsafe, and unknown results.
- Upgrades back up the old runtime, config, handoff, and changed adapters. Unchanged owned bridges refresh; unknown runtime edits stop replacement.
- Safe uninstall preserves locally edited runtimes.
- A read-only local fleet helper inspects approved project paths without executing project-local Python or changing their state.

## Install or update the Skill

```bash
npx skills add chopperH0824/agent-relay --skill agent-relay
```

GitHub CLI 2.90.0+ preview, pinned to this release:

```bash
gh skill install chopperH0824/agent-relay agent-relay@v0.1.1 --scope user
```

Updating the Skill does not automatically upgrade existing projects. Ask the agent to update a selected project while preserving its adapter scope and history. It uses the new installer's `init --dry-run`, then applies the approved plan with `--yes`. Unknown local runtime edits require review; there is no force-replace switch.

## Local fleet audit

From the installed Skill directory:

```bash
python3 scripts/fleet_report.py --root "/absolute/project-parent" --json
python3 scripts/fleet_report.py --project "/absolute/project" --json
```

Root discovery covers one directory level only. The audit uses the current trusted reader and reports installed runtime metadata separately. It does not initialize or refresh projects.

## Compatibility and boundaries

- Python 3.9+ and standard-library only.
- Schema remains `1`; report additions are documented in the bundled schema. Existing goals, tasks, events, and sealed versions are not rewritten.
- Non-Git drift covers only files selected in the latest seal, not new or unselected files. Incomplete comparisons remain unknown. Git cleanliness is not a comparison with the sealed commit.
- Relay health does not prove acceptance, approval, deployment, or current external-service state.
- Existing same-machine filesystem concurrency limits and harness compatibility evidence still apply.

## Verification

- 31 unit and integration tests, including read-only state hashes, blocked/completed separation, goal tie ordering, artifact limits, symlink handling, legacy upgrades, backups, and local-edit preservation.
- Python 3.9, 3.11, and 3.13 CI matrix.
- Skill frontmatter validation and local Agent Skills discovery.
